## 🎓 **Windows 7 Tips & Tricks**

### 🔹 **Speed Up Boot Time**
1. Run `msconfig` → Boot tab → Advanced options
2. Check "Number of processors" → set to max
3. Check "Maximum memory" → set to your RAM
4. Reduce "Timeout" to 3 seconds
5. Disable unnecessary services in Services tab

### 🔹 **Free Up Disk Space**
1. Run `cleanmgr` → Select drive → Clean system files
2. Delete `C:\Windows\Temp` contents
3. Clear browser caches
4. Remove old restore points (keep latest)
5. Uninstall unused programs

### 🔹 **Improve Gaming Performance**
1. Disable Aero theme
2. Set visual effects to "Best Performance"
3. Close background apps before gaming
4. Update GPU drivers
5. Use "High Performance" power plan

### 🔹 **Extend Windows Support**
1. Install all updates from the loader
2. Use a modern browser (Firefox ESR, Chrome)
3. Install a lightweight antivirus (Malwarebytes)
4. Enable DEP and ASLR
5. Use a standard user account daily
